TYPE
Geist Bold for headings (tight tracking), Geist Regular for text, one Instrument Serif
italic phrase per headline as the accent.

LOGO RULES
Clear space: half the mark's height on every side. Minimum size: full logo 120px / 30mm
wide, mark 20px / 5mm. Don't recolour, stretch, rotate, add effects or retype the wordmark.
